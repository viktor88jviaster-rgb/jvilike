# JviLike Mini App

Telegram Mini App для @jvilike_bot: заказ продвижения (подписчики, реакции, просмотры) и заработок на заданиях. Расчёты в TON.

## Файлы
- `index.html` — всё приложение (HTML/CSS/JS в одном файле)
- `tonconnect-manifest.json` — манифест TON Connect (замените `YOUR-DOMAIN` и положите на HTTPS)

## Запуск
1. Выложите папку на HTTPS-хостинг (GitHub Pages, Netlify, Vercel).
2. В @BotFather: `/mybots` → бот → Bot Settings → Menu Button → URL страницы.
3. В начале скрипта `index.html` заполните:
   - `API_URL` — адрес бэкенда (пусто = демо-режим)
   - `MANIFEST_URL` — ссылка на `tonconnect-manifest.json`
   - `DEPOSIT_ADDRESS` — TON-адрес для приёма пополнений

## API бэкенда (POST, JSON, в каждый запрос уходит `initData`)
| Путь | Назначение |
|---|---|
| `/me` | баланс и заказы |
| `/order` | создать заказ |
| `/tasks`, `/task/open`, `/task/check` | список, открытие и проверка заданий |
| `/withdraw` | вывод (`to`: `balance` или `out`, `wallet`) |
| `/topup` | только демо-режим |

## Обязательно на сервере
- проверять подпись `initData` (HMAC от токена бота);
- считать цены и награды на сервере, не верить значениям клиента;
- зачислять входящие TON-переводы по комментарию, каждую транзакцию один раз;
- защита от повторного выполнения заданий, холд выплат на 7 дней, лимиты на вывод.
